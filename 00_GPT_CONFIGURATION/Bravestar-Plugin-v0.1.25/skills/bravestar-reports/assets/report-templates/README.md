# Bravestar standard report templates

Version 1.0.0. Open 00-TEMPLATE-INDEX.html for the searchable catalogue. The registry contains one Markdown authoring template for every approved command in Bravestar instructions 0.1.15.

## Use
1. Select the command in 00_Template-Register/template-register.json.
2. Read the template, shared standards, evidence gate and release checklist.
3. Work on a copy outside the public repository; collect inputs and complete research before writing conclusions.
4. Populate the command-specific sections and matrices. Include original public source links and disclaimer; archive internal evidence separately.
5. Render the completed report using the print layout or an equivalent professional DOCX/PDF workflow and inspect all pages. Templates are not completed reports.
6. Send only with user authorisation and archive the exact delivered copy using the delivery procedure.

The library includes editable Markdown structures, a printable HTML design, evidence schema, checks and delivery templates. It does not itself run research, render PDFs, send emails or archive reports automatically. No test email has been sent. Report formats should be adapted to the actual sector and user scope without weakening evidence checks.

## Individual template review (v1.5.0)
Every command has specific inputs, content checks, a decision matrix and a release boundary. Read 01_Shared-Standards/REPORT-SPECIFIC-PRACTICE.md and the selected template profile. The full comparison is in 09_Quality-Checks/TEMPLATE-AUDIT.md; source applicability is in 01_Shared-Standards/TEMPLATE-BENCHMARKS.md.
