# Template-by-template review

All 78 templates were compared with the published benchmarks identified below. Existing report topics were retained. The changes make the required evidence, matrices and release boundaries explicit. These are editorial adaptations, not certification against every industry or national standard. See ../01_Shared-Standards/TEMPLATE-BENCHMARKS.md for source scope and retrieval limits.

## POL-01 — Space Policy Landscape

Previous outline: Policy instruments and status; Institutional responsibilities; Budget and implementation evidence; Implications for the company.

Existing structure retained; report-specific evidence fields and release checks needed more explicit treatment. This is a bounded benchmark review, not certification.

Benchmarks: POL2, POL7.

- Separate policy intent, adopted measures and funded implementation.
- Map objectives to the actual product and public need.
- Identify institutional competence and implementation evidence.
- Populate or justify the tailored matrix fields: Instrument,Status,Company exposure,Implementation evidence,Next decision.
- Do not describe a political announcement as an available budget.
