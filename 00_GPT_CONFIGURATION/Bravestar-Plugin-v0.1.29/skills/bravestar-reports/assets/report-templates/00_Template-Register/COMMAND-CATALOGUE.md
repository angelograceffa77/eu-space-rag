# Bravestar report catalogue

For every report offer Executive Standard (concise, essential evidence) or Detailed Report (fuller analysis and references), then email delivery Yes/No. Do not repeat answered questions. Give a time estimate before starting. Present choices in native clickable controls when available, with a short description. Otherwise use numbered choices; these template links open files, not command buttons.
