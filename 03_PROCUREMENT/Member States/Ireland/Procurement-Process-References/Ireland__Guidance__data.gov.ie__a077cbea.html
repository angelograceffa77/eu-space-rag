How To Guides

Step-by-step walkthroughs for finding datasets, exploring dashboards, and editing dashboard content.

Searching data.gov.ie

  • How to Search Datasets as a Public User Find datasets from the public site using keywords, filters, and result tools to narrow and review matches quickly.
  • How to View Dashboard as a Public User Open and navigate published dashboards from dataset pages and understand key dashboard sections as a public user.
  • How to Perform Advanced Search for Datasets Use advanced search options to combine filters and refine dataset results by relevant metadata fields.

Using the Dashboard Feature

  • How to Create Dashboard as a Private User Create a private dashboard in Superset by selecting charts, arranging layout elements, and saving draft or published versions.
  • How to Convert Your Dashboard into a Report Convert a dashboard into a report-style layout by adding headers, text blocks, dividers, and structured narrative context.
  • Adding Text to Dashboards in datAdore Insights (Superset visualisation tool) Add and format text or markdown elements in dashboard edit mode, resize them, and save the updated dashboard view.
  • Edit Chart Values Using Custom SQL Use CUSTOM SQL with CASE logic to relabel text-based chart dimension values and apply legend updates correctly.

Publishing Datasets

  • Guide for Publishers Understand how to audit your data, decide what to publish, follow Technical Framework guidance, and publish datasets manually, by API, or with a harvester.

Using data.gov.ie as a Developer

  • Developer's Corner Learn what Jupyter notebooks are, who they are for, where to find the data.gov.ie examples, and how to contribute your own notebooks.
  • Developer Resources Explore 3-star open data, CKAN API documentation and example calls, suggested datasets for analysis, and links to the portal source code.
