Download (3.61 MB) https://www.interregeurope.eu/sites/default/files/2022-02/Programme_brand_book_7.pdf 23 Feb 2022 The link has been copied Copy link Logo The programme logo is made up of the following elements: The logo-type with the coloured arch inside; The EU emblem and; The co-funding statement. It is surrounded by an area of clear space that defines the minimum distance to other elements such as other logos, pictures, texts or any other design elements. The minimum logo width is 20 mm. Important The proportion and relationship of size between the logo elements must not be changed. How to apply our logo We have four different logo versions: Standard logo Pantone CMYK Black and white monochrome Negative or white version Each logo has a specific use: In full colour (preferred option) Whenever possible, use the logo in its full-coloured version. You must place a white outline around the EU flag. The outline equals 1/25th of the EU flag's height. For single colour reproductions and engravings Use a black version of the logo in single-coloured reproductions and engravings. Only use this version when a four-coloured process is not available. The width of the EU flag outline equals 1/25th of the EU flag height. For single colour reproductions and engravings on a very dark background Use a white version of the logo in single-coloured reproductions and engravings with a very dark background. Only use this version when a four-coloured process is not available. The width of the EU flag outline equals 1/25th of the EU flag height. The kit includes: A project branded logo set (see example below) A project poster for A3 print A project presentation template Project social media templates Do not alter the project branded logo set. You can only adjust its size, but you must keep a minimum width of 20mm. Project partners and their communication managers have the project branding guidelines available below together with the templates. Additional branding elements Hexagon The hexagon, with slightly rounded corners, is a repetitive element of the visual identity. You can use the it in presentations, infographics and even for framing images. Do not alter the proportion and rotation of the hexagon. Topic colour line The coloured line, composed of the six topic colours in specific order, can be used to highlight and reinforce the visual identity on various supports. Do not alter the order in which the colours appear. 3D diamond element Only use this dynamic element on the cover or back pages with limited amount of text. For individual topics, the respective colour element can be used to create a monochrome texture. In case of borderless printing, please ensure careful trimming and prepare the bleed area correctly.
